# DelayUni — VST3 аудио-плагин эффекта задержки (Delay)

## О проекте
Учебный проект по разработке аудио-плагина на чистом VST3 SDK (без использования JUCE). 
Плагин реализует классический эффект задержки (Delay) с возможностью управления параметрами в реальном времени.

## Функционал
- Задержка аудиосигнала от 10 до 2000 мс.
- Регулировка обратной связи (Feedback).
- Баланс сухого и обработанного сигнала (Mix).
- Режим Bypass.
- Стерео-обработка.
- Сохранение состояния (пресеты).

## Технологии
- **Язык:** C++ (стандарт C++17)
- **SDK:** Steinberg VST3 SDK
- **Система сборки:** CMake
- **Среда разработки:** Visual Studio 2022

## Сборка проекта
1. Клонируйте репозиторий (убедитесь, что VST3 SDK находится в доступном месте).
2. Настройте путь к VST3 SDK в `CMakeLists.txt`.
3. Выполните генерацию проекта:
   ```bash
   cmake -B build -G "Visual Studio 17 2022" -A x64
